# 0001 — 一次錯誤學到的東西，要住哪一層

- **狀態**：已採用
- **日期**：2026-08-29
- **格式**：MADR 精簡版。決策紀錄一個檔一件事、編號、**採用之後不改**；
  要改就寫下一號並標明它取代了誰。

## 脈絡

nova 每次踩到錯，都會產生一句「以後要記得⋯⋯」。原本的做法是把它加進
CLAUDE.md，於是那個檔長成了流水帳——固定負控表一路長到 40 幾列，
規則本身被事件淹掉。使用者當場否掉：「不要把 CLAUDE.md 跟 rule 當流水帳，
帳本是另外的」。

問題不是「要不要記」，是**記到哪一層**。

## 決策

錯誤學到的東西過這個四岔口，停在第一個成立的那格：

```
一次錯誤發生
  │
  ├─ ① 能用機械判準抓嗎？
  │      能 ──→ 閘／hook／測試                    保證：違反不了
  │
  ├─ ② 抓不到「做對沒」，抓得到「有沒有做」？
  │      是 ──→ 工作流多一個階段或判準            半保證：狀態機逼它走過
  │
  ├─ ③ 只有某些任務才需要知道？
  │      是 ──→ skill（按需載入）                 不佔每次的 context
  │
  └─ ④ 每次都要、又機械不了
         └──→ CLAUDE.md／rules                    加速器：會過期，要短
```

**只是「這次發生了什麼」的，四格都不進**——那是資料不是規範，寫進 commit 訊息、
測試 docstring、`docs/負控紀錄/`，或 nova 執行時的帳本。

進第 ④ 格之前要先答一題：**這條寫得出會失敗的測試嗎？** 寫得出來，
它就該在第 ① 格，不該在提示裡。

## 理由

Anthropic 官方的 Claude Code best practices 用的是同一組區分（原文）：

> Unlike CLAUDE.md instructions which are **advisory**, hooks are
> **deterministic and guarantee the action happens.**

> **Ruthlessly prune.** If Claude already does something correctly without the
> instruction, **delete it or convert it to a hook**.

> Bloated CLAUDE.md files cause Claude to **ignore your actual instructions**.

第三句是關鍵：規則檔變長不只是浪費，是**讓其他規則失效**。所以往 ④ 加東西
有實際成本，不是「多寫一句沒差」。

第 ③ 格也是官方講的：「For domain knowledge or workflows that are only
relevant sometimes, use skills instead. Claude loads them on demand without
bloating every conversation.」

這跟 nova 自己的判準是同一件事，只是換句話說：**規則寫在提示裡是虛線的懇求，
寫在包住執行者的程式碼裡才是實線的保證。**

## 後果

- CLAUDE.md 的固定負控表搬到 `docs/負控紀錄/`，本檔留一行指標。
- CLAUDE.md 加一條行數上限（ratchet），由 `test_CLAUDE_md不准無限長` 背書。
  **官方沒有給行數，只說「keep it short」**，所以上限是釘現況不是引用權威。
- 文件即事實的掃描範圍要跟著擴，否則搬出去的 40 個測試名就沒人檢查了。

## 已知沒做到的部分

- **第 ④ 格的「有沒有用」還沒有判準。** 業界做法叫 prompt eval／regression：
  同題目、同一顆腦、有無那條規則各跑數次比錯誤率。沒有對照的規則加了等於沒加，
  只是讓人以為加了。目前靠人判斷。
- **這份決策本身是文件，不是殼。** 分類要靠人做，機械擋不住「該進①卻寫進④」。
  唯一機械化的部分是行數上限——它擋得住「④ 無限長」，擋不住「④ 裡放錯東西」。

## 之後可能怎麼走

`docs/負控紀錄/` 是手工版的 mutation testing。機械版是 `cosmic-ray`／`mutmut`，
會直接算出 mutation score，不必人維護表格。導入前有兩個前置問題：

1. 這些工具吃不吃**中文識別字**？整個 codebase 都是——工具嗆到就免談。
2. 跑的位置只能是 nightly 或按需，**永遠不進提交閘**（提交閘的預算是 10 秒，
   mutation testing 是分鐘級）。
