# 額度在狀態機之前短路成「等重置」

- 日期：2026-09-03
- 票：22a-1
- 登記：`tests/負控/登記們/額度短路.py`
- 識別：`額度短路那一格一律回None讓額度掉回狀態機`
- 最多秒：120

## 守的是哪一格

`迴圈/工作流.py` 的 `_額度就等重置(...)`：撞到上游額度時，在**進狀態機之前**
把收場岔成 `結束代碼.額度`。這一格不在的話，狀態機會把所有「角色確定失敗」
壓成同一個 `中止`（退出碼 1＝東西壞了、人來修），而額度沒有東西要修——
2026-09-02 四條線同一分鐘死掉、72 分鐘沒有任何機制會動，就是那個壓扁的結果。

**外表毫無異狀**是這一格特別需要負控的理由：工作流照樣跑完、照樣收場、
照樣寫成果帳，只是收在錯的那一類。沒有任何測試以外的東西會叫。

## 變異

錨點吊在 `def _額度就等重置(` 這一行（函式簽章＝這一格的介面），
不吊在會被重寫的函式本體。做法是把同名的前置樁插在原函式之前、
原本那支改名 `_額度就等重置_被樁蓋掉的`——Python 後定義的名字會蓋掉前面的，
不改名的話樁形同不存在（刀會 SURVIVED，但原因是刀沒咬到，不是保證還在）。

樁一律回 `None` ＝ 額度掉回狀態機。
