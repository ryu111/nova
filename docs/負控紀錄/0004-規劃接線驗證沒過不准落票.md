# 規劃接線：驗證沒過不准落票

## 固定負控（2026-09-01）

`載體/規劃成票.py` 把「目標 → 規劃輸入 → `執行計畫員` → `驗證分派單` → 票」
串起來。這條鏈上唯一擋得住模型亂講的就是那三行：

| 破壞什麼 | 該紅的測試 |
|---|---|
| 拿掉 `規劃成票` 裡的 `if 問題們: raise 分派單不合格(問題們)` | `tests/單元/test_規劃成票.py::test_缺欄的分派單不准落票且訊息指名哪一項缺哪一欄` |

親眼看到紅（1 failed, 1 passed）：`Failed: DID NOT RAISE 分派單不合格`。還原後兩支全綠。

**這一格危險的地方在於紅得不夠痛**：拿掉守衛之後，那張缺停止、缺驗收出口的
分派單不是炸掉，是**安靜地落成一張「## 驗收」「## 停止」底下空無一物的票**。
`收件.缺哪幾欄` 看標題，那張票四個標題都在——**它過得了四欄檢查，卻沒有任何
機械停止條件**。所以四欄檢查擋不了這一條，能擋的只有 `驗證分派單`；
另一支測試（票過得了 `缺哪幾欄`）保的是相反方向——別生出自己會擋下來的票，
兩支合起來才把「假綠」的兩邊都封住。
