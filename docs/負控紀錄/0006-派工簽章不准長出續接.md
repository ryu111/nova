# `nova.派工` 的公開簽章不准長出續接類參數

## 這是「還沒發生的洞」的把關器

CLAUDE.md 硬規則二：**不得讓同一個對話自寫自評**，而判準是**對話不是家族名**。

現在這條保證是**結構性**的：`nova.派工` 收不到續接，所以做事與審查一定是
兩個新對話（三家不給續接時本來就都開新的：codex `--ephemeral`、
claude 不給 `--resume`、agy 不給 `--conversation`）。

`tests/單元/test_換腦判準.py::test_角色結構上不可能續接到同一個對話`
守的是**角色那一層**。這一支守的是**公開 API 那一層**——
那天有人給 `派工` 加上 `續接`，角色那層可能還是乾淨的，
而兩邊續接到同一個識別碼就是自寫自評，**沒有任何測試會紅**。

## 固定負控

| 破壞什麼 | 該紅的測試 | 親眼看到 |
|---|---|---|
| 在 `src/nova/__init__.py` 的 `派工` 簽章加一個 `續接: str \| None = None` | `tests/整合/test_換腦判準.py::Test換腦判準::test_派工的公開簽章不准長出續接類參數` | 紅：``assert not ['續接']`` |

還原後 3 passed。

**這支紅的時候不是要人把它刪掉**——訊息就寫著正解：
「要加這個參數，就要在同一格加上『做事與審查的對話識別碼不准相同』的檢查，
並把這支測試改成驗那個檢查」。
