# 收尾現場：未定義的狀態不准落成「可合併」

**日期**：2026-09-02
**保證**：`gh` 回一個我們沒定義過的 `mergeStateStatus` 時，收尾現場要收成
**結果未知（碼 3）**，不准落進「預設可合併」。

## 破壞什麼

`src/nova/載體/收尾現場.py` 的 `_觀測狀態`：

```python
    except ValueError:
-       return 收尾狀態.UNKNOWN
+       return 收尾狀態.CLEAN    # 未定義的字串靜靜當成可合併
```

## 該紅哪一支

`tests/整合/test_收尾現場.py::Test現場查詢與結果正規化::test_未定義狀態回未知三且不落入預設可合併`

## 實測輸出

```

E       AssertionError: assert 0 == 3
E        +  where 0 = 收尾快照(…, 狀態=<收尾狀態.CLEAN: 'CLEAN'>, 退出碼=0,

```

還原後：`21 passed`。

## 為什麼這一格值得一把刀

碼 3 的語意是「**不知道工作做了沒**」，而收尾的下一步是合併。
把未知靜靜讀成「可合併」等於在不知道的情況下按下合併鍵——
那正是三值終局要防的事。破壞之後退出碼從 3 變成 0，**而且沒有任何別的測試會紅**，
所以這一支是這條保證唯一的守門人。

還原用 `cp` 備份，不是 `git checkout --`（工作樹裡有未提交的東西）。
