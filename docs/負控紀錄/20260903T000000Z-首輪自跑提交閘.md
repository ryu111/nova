# 首輪實作員收尾前自跑一次提交閘

## 固定負控

首輪 `impl` 的讀取策略要它收尾前自己跑一次 `uv run nova 閘 提交`、紅了當場修、
回報貼結果，並講明「這是自我檢查不是驗收，驗收由下一階 verify-green 做」；
同時舊的兩句（`**不要自己跑全套測試**` 與「驗證是 verify 階段的事」）留著不動。

| 破壞什麼 | 該紅的測試 | 親眼看到 |
|---|---|---|
| 從 `_首輪讀取策略` 刪掉新加的那一段（還原成原本三句） | `tests/單元/test_角色提示.py::Test首輪實作員自跑提交閘::test_首輪要求收尾前跑一次提交閘且紅就當場修` | KILLED |
| 把新加的那一段搬到 `_退回輪讀取策略`（首輪還原） | 同上（首輪三格紅、退回輪那格也紅） | KILLED |
| 從 `_首輪讀取策略` 刪掉 `**不要自己跑全套測試**` 那一句（新段落留著） | `tests/單元/test_角色提示.py::Test首輪實作員自跑提交閘::test_舊的兩句沒被順手刪掉` | KILLED |

第二把刀守的是「加在首輪不是加在退回輪」：搬錯地方的話兩段都還在檔案裡，
字串搜整個模組照樣找得到，那是最像綠的一種假綠。

哨兵的斷言是整句、不是零散關鍵字的 `or`：
「不是驗收」那格斷言 `**這是自我檢查不是驗收**：驗收由下一階 verify-green 做` 一整句，
回歸那格斷言原文 `驗證是 verify 階段的事`（新段落裡的 `verify-green` 不算數）。

變異登記在 `tests/負控/登記們/首輪自跑提交閘.py`；本輪三筆逐一重跑，皆為 KILLED。
