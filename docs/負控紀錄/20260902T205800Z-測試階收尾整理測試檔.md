# 測試階收尾整理測試檔

## 固定負控

測試階跑完後只對動過的測試檔呼叫整理器（`ruff check --fix` ＋ `ruff format`），
消掉排版與 safe fix 問題，避免排版紅流到實作員手上撞護欄。

| 破壞什麼 | 該紅的測試 | 親眼看到 |

| 把工作流主迴圈中測試階結束後的整理器呼叫拿掉（測試階不再整理） | `tests/單元/test_工作流.py::Test測試階收尾格式化::test_測試階跑完會對動過的測試檔跑格式化` | KILLED |

實測變異斷言：`assert [] == [('tests/單元/test_新寫的.py',)]`，變異已確認為 KILLED。
