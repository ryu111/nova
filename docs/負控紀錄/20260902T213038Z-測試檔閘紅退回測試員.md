# 提交閘只紅在測試檔的 lint／型別時退回測試員

## 固定負控

`全綠了嗎` 紅在提交閘、`閘紅：` 只點名 `ruff-check`／`ruff-format`／`mypy`、
而且抽得出的路徑全在 `tests/` 底下時，那一輪退回測試員（第一次紅就退）。
其餘一律照舊回實作員。

| 破壞什麼 | 該紅的測試 | 親眼看到 |
|---|---|---|
| 把 `狀態機.py:_改道去哪` 裡 `_測試檔閘紅該退回測試員` 那條分流拿掉（`驗證綠` 紅一律回 `階段代碼.實作`） | `tests/單元/test_狀態機.py::test_驗證綠紅在測試檔的ruff就退回測試員` | KILLED |

手動變異：刪掉那兩行後跑 `uv run pytest tests/單元/test_狀態機.py -q`，
得到 `1 failed, 45 passed`（紅的正是上表那一支）；改回來後 `46 passed`。
