# 儀表板圖上的一段寬度也是一句陳述句

## 固定負控

`docs/負控紀錄/0026-儀表板每個數字只有一個來源.md` 那幾把守的都是**數字**：
少一格、算不出來被畫成 0、模板自己補一個上去。**圖形是另一條路徑**：
每個數字都對，而收件匣那條照樣按設計稿當天的 50／25.6／19.5 分段——
畫面用 10:05 那一刻的比例陳述今天的事，而且它不會觸發任何一個
「未接線」或「少一格」的檢查，那些檢查全部只看文字。

人是先看圖再看數字的。**一張永遠長一樣的圖，比一個沒有數字的空格更會騙人。**

同一條路徑上還有一句話：失敗碼那張表底下的**結論句**。它跟段寬一樣是
「資料之外的陳述」，只是長成文字——設計稿當天排第一的是「未知」，
所以那句寫的是「不知道工作做了沒，只能人去看」。額度用完的那一天排第一的是
`quota-exhausted`（換一家立刻重跑就好），照樣被那句話說成結果未知，
讀的人便照 at-most-once 不敢重跑。**每個數字都是對的。**

| 破壞什麼 | 預期被哪裡抓到 |
|---|---|
| `src/nova/載體/儀表板/模板.html` 收件匣第一段的寬度 placeholder 換回設計稿的 `width: 50%` | `tests/單元/test_儀表板模板.py::Test圖形比例由資料算出::test_圖形比例由契約值算出_兩組資料比例不同` |
| `src/nova/載體/儀表板/模板.html` 的 `${失敗碼_第一名處置}` 換回設計稿那句「「不知道工作做了沒」，腳本不准重跑，只能人去看」 | `tests/整合/test_儀表板命令.py::test_第一名失敗碼的解釋句由種類決定_quota不准說成未知`、`tests/單元/test_儀表板模板.py::Test模板就是設計稿去殼::test_主模板的變數跟契約一一對應` |
| `src/nova/載體/儀表板/模板.html` 把門檻圖的中央刻度（`left: 50%`）塞回閘鎖那張卡 | `tests/單元/test_儀表板模板.py::Test模板就是設計稿去殼::test_模板沒有省略段與門檻條_且骨架允許刪段` |

登記在 `tests/負控/登記們/儀表板.py`（一線一檔）。

## 實測

三把都 **KILLED**（`tests/負控/執行器.執行變異`，2026-09-03）：
`儀表板圖形段寬換回設計稿常數`、`儀表板第一名失敗碼的處置句寫死`、
`儀表板門檻圖的中央刻度塞回閘鎖卡`。

砍下去留下的痕跡是這樣：第一把讓那一段固定 50%，而
`test_圖形比例由契約值算出_兩組資料比例不同` 拿**兩組不同的契約值**各渲染一次
（6:3:1 要畫成 60／30／10、1:1:2 要畫成 25／25／50）——一個常數答不出兩組比例。
第二把把處置句釘死，整合那支拿 `quota_exhausted` 排第一渲染一次，
頁面會對一個確定失敗說「不知道工作做了沒」；單元那支窮舉主模板的變數，
placeholder 換成常數就少一個變數。第三把把門檻圖的中央刻度塞回閘鎖那張卡，
`test_模板沒有省略段與門檻條_且骨架允許刪段` 會指著那個行內 `position: absolute`
說契約裡連門檻位置都沒有。
