# 審查腦不可達就別開跑，免得前三階白燒 2.5M token

## 現場

`_工作流前置檢查` 只查審查家的**資格**（本地腦能不能當審查員、有沒有被熔斷），
那些全是本地資料。資格不等於可達——判準三：**墊片證明的是轉遞形狀，不是可達性。**

額度用完或認證過期的審查腦，資格檢查一路放行，於是：

```
test（模型）     ~500-850k   ← 燒掉
impl（模型）     ~500-850k   ← 燒掉
refactor（模型） ~500-850k   ← 燒掉
review           中止 → 不接著排，下一輪從頭來
```

## 改法：開跑前一次版本查詢級的探測

`模型/轉接.可達嗎(家)` 跑 `<執行檔> --version`（零 token、亞秒級）。
**不發真實問答**——那本身就是在燒 token 防燒 token。

| 情況 | 回什麼 | 為什麼 |
|---|---|---|
| 版本查詢結束碼 0 | `True` | 碰得到 |
| 版本查詢結束碼非 0 | `False` | 環境真的說了不，這一格答得出來 |
| 找不到執行檔（`FileNotFoundError`） | `None` | 分不出「這家掛了」跟「這個 process 的 PATH 上沒有」（launchd 起的 daemon、測試的假 PATH 都屬後者）→ **算不出來** |
| 逾時、OSError | `None` | **算不出來**，照 `載體/線.py` 的慣例留空不拿 `False` 頂替 |
| `local` | `None` | 走 HTTP 沒有 CLI，**這一家跳過這道檢查**，不為了對稱而發真問答 |

擋的判準是 `_審查腦碰不到的理由`：**整條接力鏈都是 `False` 才擋**（`--審查用 a,b`
是接力，照第一家算的話接力機制等於沒有）；`None` 不擋——擋錯的代價是整條線
停在阻擋碼（不接著排）而沒人知道為什麼，放行的最壞情況只是回到沒有這道檢查的今天。

這道檢查掛在 `_工作流開跑前` 的**最後一格**（資格、祕密檔、預算鎖之後、建腦之前）：
它是那一串裡唯一會 fork 子程序的，而被預算鎖擋下的那一輪連一次子程序都不該起
（`tests/整合/test_預算鎖接線.py` 就是數那個）。擋的位置仍在建腦之前，
所以三個模型階段照樣一次都不會被叫到。

## 固定負控

| 破壞什麼 | 該紅的測試 | 親眼看到 |
|---|---|---|
| `_工作流開跑前` 裡呼叫 `_審查腦碰不到的理由` 那一段拿掉 | `tests/整合/test_審查腦可達性.py::Test審查腦不可達就別開跑::test_零個角色被呼叫` | FAILED：`審查腦不可達，卻還是叫了 1 次模型——那就是沉沒的 token`（stderr 看得到 `→ test` 那一階已經跑起來） |
| `轉接.可達嗎` 的 `FileNotFoundError` 那格改回 `return False` | `tests/單元/test_可達嗎.py::Test可達嗎的四格::test_找不到執行檔是算不出來` | FAILED：`assert False is None`；順帶會讓整合層 11 支（`tests/整合/test_單次token護欄.py`／`tests/整合/test_工作流逾時.py`／`tests/整合/test_收尾跑驗收.py`／`tests/整合/test_模型旗標.py`／`tests/整合/test_預算鎖接線.py`）一起紅在「還沒開始就擋下來」 |

反向那一面由 `tests/整合/test_審查腦可達性.py::Test接力鏈還有備援就照跑::test_第一家不可達第二家可達時工作流照跑`
守著：少了它，這道檢查會把「還有備援」的情況一起擋掉。
