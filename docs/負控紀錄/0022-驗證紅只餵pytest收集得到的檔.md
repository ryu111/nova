# 驗證紅只餵 pytest 收集得到的檔

## 現場

「動過的測試檔」（護欄的知識）跟「pytest 目標」（判準的知識）本來是同一個集合。
護欄故意不看檔名——`tests/` 底下全算，含 fixture、含被刪掉的檔（實作員動 fixture
也是動測試），那一格是對的。錯的是下游把同一份清單原封不動接上 pytest 命令列：

- 2026-09-02 09:50（run 92cfcd）：`tests/資料/儀表板設計稿CSS.css` 上了命令列，
  pytest 對非 `.py` 沒有 collector → `ERROR: not found`（exit 4）→
  `判準終局.跑不起來` → 步驟終局「結果未知」→ 工作流停掉。**一支測試都沒跑到**
  （`no tests ran in 0.02s`，那 6261 ms 全花在等閘鎖）。
- 2026-09-02 01:34（run 128d6f）：同一個洞，換成 `實錄/*.json` 與 `README.md`。
- 2026-09-01：同一個洞的第一次，`登記們/*.py` → exit 5。

三次都是「補一條排除項」收場，所以第四種副檔名一定會再來。這一輪把問題換掉：
不問「在不在黑名單上」，問「pytest 收得到嗎」——`可作指定pytest目標` 改成對齊
pytest 自己的 `python_files`（`test_*.py`／`*_test.py`）的 allow-list，原本那五條
排除項（登記們、`登記.py`、`執行器.py`、`conftest.py`、`__init__.py`）全被同一條
涵蓋，順帶關上還沒被踩的 `tests/負控/跑前體檢.py`。另一半是存在性：改名 ＝ 刪＋加，
舊路徑餵給 pytest 一樣 exit 4，所以 `_只驗這輪新寫的測試` 多問一句「它還在工作樹上嗎」。

exit 4／5 收成「跑不起來」的映射沒動——那個映射是對的，錯的是上游餵了不該餵的檔。

## 固定負控

登記在 `tests/負控/登記們/驗證紅只餵測試檔.py`（一線一檔）。

| 破壞什麼 | 預期 | 實際 |
|---|---|---|
| `載體/判準.py` 的 `可作指定pytest目標` 檔名比對改成 `return True`（＝退回「什麼都能當目標」） | `test_指定測試目標政策.py::…::test_pytest收集不到的檔不能當目標` 與 `test_驗證紅只餵pytest收集得到的檔.py::test_動過的測試檔含fixture與已刪檔時工廠只收到活著的測試檔` 要紅 | KILLED——`.css` 又進了工廠，就是 494 那條路 |
| `迴圈/工作流.py` 的 `_還在工作樹上` 尾行 `return (工作目錄 / 檔).is_file()` 改成 `return True` | `test_驗證紅只餵pytest收集得到的檔.py` 的兩支要紅 | KILLED——改名前的舊路徑（`tmp_path` 底下那支 `test_丙.py`，樹上沒有這個檔）又被接上命令列 |

釘子那半邊另外算一把（同檔登記，不算進上面兩把真因刀）：

| 破壞什麼 | 預期 | 實際 |
|---|---|---|
| `迴圈/狀態機.py` 的 `_失敗行樣式` 把 `(\S+::\S+)` 換成只吃 ASCII 的字元類 | `test_狀態機.py::test_失敗行的nodeid帶轉義或未轉義的中文參數id都抽得完整` 要紅 | KILLED——轉義的 `[\u5100\u8868\u677f]` 截成 `tests/x.py::T::test_a[`，中文的 `[儀表板]` 同樣截斷 |

既有那把刀（`登記們/驗證紅挑錯檔.py` 的「指定測試目標不再排除負控登記們」）錨點
跟著搬：deny-list 的 `return False  #: 負控登記們` 在 allow-list 之後不存在了，
改砍同一個保證現在住的那一行，`該紅` 沿用原本那兩支。重跑 KILLED。

四把刀都親手下過一次、跑完還原，`git status` 確認 src 沒殘留；
CI 上由 `tests.負控.執行器.執行變異` 再跑一次。

## 沒做的

轉義的中文參數 id（`[\u5100\u8868\u677f]`）**不是真因**，只釘住不改：`結果未知` 只從
`判準終局.跑不起來` 來，跟 `FAILED` 行怎麼解析無關；所有 nodeid 比對都是「轉義 vs
轉義」，同一份 pytest 設定下兩邊一致。不關 `pyproject.toml` 的轉義選項、不在解析器
裡 `unicode_escape` 解碼。做的只有一支釘子測試（`test_失敗行的nodeid帶轉義或未轉義的
中文參數id都抽得完整`）：兩種長相都要抽出完整 nodeid，之後真要關掉轉義是純設定題，
不必回頭改解析器。它一寫就綠，守著它的是上面那把 ASCII-regex 刀。
