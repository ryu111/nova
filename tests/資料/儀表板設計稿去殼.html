工作做完會回報一個數字，告訴你「怎麼結束的」：
  • 0 成功——做完了，沒問題。
  • 1 失敗——確定沒做成。
  • 3 不知道——電話斷了，不知道他做完沒。像你叫人去買牛奶，講到一半斷線——你不能再叫一次，不然可能買回來兩瓶。所以這個數字的規矩是「不准重來」。
  • 4 安全鎖擋住——不是壞掉，是它照規矩把你攔下來了。像安全帶扣住你，那是它在做事，不是它故障。規矩是「不准去把鎖拆掉」。

「負控」是這樣一件事：你怎麼知道保全系統真的有在運作？故意去弄壞一次，看警報會不會響。
  • 166 把刀——做過 166 次這種測試，而且電腦會自己重做，所以是真的保障。
  • 16 份紀錄——寫在紙上給人看的，電腦不會自己重做。
  • 0 條閘在檢查——沒有任何人在確認「新的保護有沒有做過這種測試」。
  • 0 個階段被指派——連「誰該去做」都沒有規定。
後面兩個 0 就是為什麼前面兩個數字對不上。
